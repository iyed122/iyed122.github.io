TELNET Holding · end-of-studies project · 2026

Enterprise AI Assistant — Graph-RAG with a self-improving evaluation loop

An on-prem assistant that answers engineers' questions from Jira, Confluence and GitLab, cites every source, and only ships a fine-tuned model when the evidence clears a pre-set bar. Sold by TELNET to a client.

94.8%answers grounded in a quoted source
2.1σgate-cleared promotion (n = 366)
2.4×faster answers
How it works
  • Graph-RAG: vector search over 1.28 M chunks in Neo4j, then multi-hop traversal of typed ticket links.
  • Agent: a bilingual LangGraph agent routes each question to the graph, the live APIs, or both in parallel.
  • Evaluation: every answer scored by RAGAS and a deterministic validator that can veto the judge.
  • Gated fine-tuning: RAFT adapters on a 6 GB GPU; a promotion gate refused the first run and promoted the second.
